I’m exploring focused tools that solve one real problem well—from browser utilities to reusable frontend components.

01 CONCEPT

BROWSER API · RESILIENCE

Network State

A tiny browser utility for apps that need to respond thoughtfully to connectivity changes, failed requests, and recovery—not just a green “online” indicator.

What I want to get right A small API, clean event lifecycle, predictable state transitions, and clear docs about what browser connectivity signals can and can’t tell you.

Not built yet
02 CONCEPT

DEVELOPER TOOL · BROWSER STORAGE

Storage Inspector

A lightweight local tool to inspect, search, edit, and export localStorage and sessionStorage while debugging a web app.

What I want to get right Safe editing, readable values, quick filtering, and an interface that makes debugging less fiddly.

Not built yet
03 LIVE TOOL

BROWSER TOOL · TEXT PROCESSING

Text Inspector

A privacy-first text utility for word, character, sentence, and paragraph counts, reading-time estimates, repeated-word detection, and whitespace checks. Everything runs locally in your browser.

Built with React, TypeScript, Vite, and Vitest. No account, backend, or text uploads.

COMPONENT LIBRARY · ACCESSIBILITY

Command Menu

A compact, keyboard-first command menu with search, groups, and sensible accessible defaults for product interfaces.

What I want to get right Keyboard interactions, focus management, screen-reader behavior, and an API that stays easy to use.
